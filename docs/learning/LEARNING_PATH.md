# Cella — Learning Path

## Purpose

This document defines the actual learning path for building Cella.

`PREREQUISITES.md` describes the knowledge that Cella may require throughout its development.

This document is different: it defines **when and why I need to learn each topic**.

The goal is not to finish every prerequisite before writing Cella.

Instead, Cella will be developed using the following cycle:

```text
Learn concept
     ↓
Understand why Cella needs it
     ↓
Experiment with it
     ↓
Implement it in Cella
     ↓
Test and observe it
     ↓
Study deeper when necessary
     ↓
Document what was learned
     ↓
Continue
```
